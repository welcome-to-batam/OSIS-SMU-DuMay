# OSIS-SMU-DuMay
OSIS (Organisasi Siswa Intra Sekolah) OSIS merupakan wadah organisasi siswa untuk mengembangkan kreativitas, kepemimpinan, kedisiplinan, dan kerja sama. Menjadi pusat informasi, kegiatan, aspirasi, serta komunikasi antarwarga sekolah demi menciptakan lingkungan sekolah yang aktif, kreatif, dan berprestasi.
